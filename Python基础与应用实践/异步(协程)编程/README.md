## 5. 智能体的异步调用(ainvoke, astream)

在模型中使用异步的原因:
    -给HTTP协议，延时，利用延时的时间，来完成其他任务，等延时结束后，继续处理->充分利用CPU时间效率在使用异步编程，在HTTP协议下，异步编程会成为常态，- 如下是两个经典场景:
模型与智能体(模型本身是Web service:HTTPX)
远程工具(Model context Protoco1: MCP:工具的本身的价值就是给Model，Agent提供上下文提示词)-工具返回:“字符串”，充当提示词的上下文。Qwen tokenizer.apply chat template(tools, documents)
