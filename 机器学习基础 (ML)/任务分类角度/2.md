# 科学算法对机器学习的影响

## 梯度下降算法的根本特性是可导，这点是必要的

真实值提供“目标”，损失函数提供“方向”，梯度下降提供“更新”。

## 更完整的机器学习三层框架

其实可以拆成三层：

### 第一层：学习范式（怎么获得反馈）
监督

无监督

半监督

自监督

强化

决定：损失函数 / 奖励信号 / 更新目标

### 第二层：建模思想（参数怎么组织）
线性

树

核

概率

距离

神经网络

决定：假设空间 / 参数结构 / 输出形式

### 第三层：优化方法（参数怎么改）
梯度下降

随机梯度下降

牛顿法

EM 算法

坐标下降

闭式解

决定：具体更新公式 / 收敛路径 / 计算效率

## 结论

学习方式主要决定模型从什么信号中获得反馈、损失或奖励如何定义，从而影响参数更新的方向和目标。
建模思想主要决定模型假设空间、参数结构和输出形式。
优化方法则决定参数具体如何迭代更新。
三者共同决定一个机器学习模型的行为，但并非完全独立，某些模型会天然绑定特定的学习方式或优化方法。
