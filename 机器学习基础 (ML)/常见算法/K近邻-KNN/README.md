# KNN

KNN 就是在特征空间中找离新样本最近的 K 个训练样本，用它们的标签来决策。

## 核心思想：物以类聚

KNN 基于一个朴素假设：特征空间中距离相近的样本，标签也倾向相同。
它不做任何“学习”，fit 阶段只是把训练数据存起来。预测时：

1. 计算新样本到所有训练样本的距离

2. 选出距离最近的 K 个

3. 根据这 K 个的标签做决策

### 第一步：距离怎么算
最常用的是欧氏距离。对于两个样本 x 和 z，各有 n 个特征：

```text
d(x, z) = √( (x₁-z₁)² + (x₂-z₂)² + ... + (xₙ-zₙ)² )
```

其他可选距离：

距离	公式	特点
欧氏距离	√Σ(xᵢ-zᵢ)²	默认，适合连续特征
曼哈顿距离	Σ|xᵢ-zᵢ|	对异常值更鲁棒
余弦距离	1 - cos(θ)	适合文本、方向性数据
闵可夫斯基	(Σ|xᵢ-zᵢ|^p)^(1/p)	欧氏和曼哈顿的泛化
关键点：距离计算对特征尺度极其敏感，所以标准化是 KNN 的前置必做步骤。

### 第二步：K 个邻居怎么决策

**分类任务：投票**

K 个邻居中，哪个类别最多，就预测为哪个类别

平票时 sklearn 默认选距离更近的那个类（按距离加权投票）

**回归任务：取平均**

预测值是 K 个邻居标签的均值

也可以按距离加权平均，近的邻居权重更大

###  第三步：K 值怎么选

K 是 KNN 唯一的超参数，直接决定模型行为：

K 值	效果
K 太小（如 1）	对噪声极敏感，容易过拟合。一个异常点就能改变预测
K 太大	决策边界过于平滑，容易欠拟合。邻居里混入太多其他类
合适 K	在偏差和方差之间平衡
经验法则：

分类问题：K 通常取奇数，避免平票

常用起点：K = √n（n 为训练样本数）

最终靠交叉验证选最优 K

## KNN的特点与优缺点

### 第一，没有泛化抽象能力。

线性回归会学出“收入每增加 1 万，房价涨 5 万”这样的全局规律。即使某个样本噪声很大，它也能靠整体趋势抵消。

KNN 不会。它只记得“这个点附近有这些点”，学不出任何可解释的规律。一个新样本落在数据稀疏的区域，它的 K 个邻居可能离得很远，投票结果就近乎随机。

### 对数据缺陷零容忍。

投票预测质量完全依赖空间数据质量，没有纠错能力。

数据问题	KNN 的反应
特征尺度不统一	大尺度特征主导距离，其他特征失效
有无关特征	稀释真正有用特征的距离贡献
有异常值	异常值持续误导周围预测
类别不平衡	投票天然偏向多数类
高维	距离失去区分度，近邻变“远邻”
数据稀疏区域	邻居很远，预测不可靠
其他算法多少有内置机制缓解这些问题，KNN 几乎没有。

### 预测阶段没有“学习”发生。

它不总结规律，只是查表。所以它无法回答“为什么是这个预测”，也无法在新数据上做外推。

### KNN 并非一无是处，它在特定场景下非常有效

1. 数据质量高、维度低、样本充足时

比如手写数字识别（MNIST 的简化版）、简单的推荐系统、低维分类任务。数据干净、特征有意义、样本够密，KNN 可以表现得很好。

2. 作为基线模型

它实现简单、无需训练，可以快速给出一个“数据本身能达到什么水平”的参考。如果复杂模型还不如 KNN，说明数据或特征有问题。

3. 局部模式明显、全局规律弱的场景

有些问题本质上就是“相似的东西归一类”，没有简洁的全局公式。这时 KNN 的局部投票反而比强行拟合全局模型更自然。

4. 在线学习/增量场景

新数据直接加入训练集即可，不需要重新训练。这是懒惰学习的天然优势。

## 总结

不是“KNN 不靠谱”，而是：
KNN 的可靠性 = 数据质量 × 特征设计 × K 值选择。

它把模型复杂度的责任完全转移给了数据和特征工程。如果你愿意花力气清洗数据、选特征、做标准化、调 K 值，KNN 可以很靠谱；如果你指望它自动处理脏数据，它一定会让你失望。

所以实践中，KNN 通常不是首选，而是：

数据干净、维度低时的轻量方案

复杂模型的基线对比

教学和理解“局部性”概念的经典案例

一句话：KNN 不骗人，它只是把数据的真相直接暴露给你。
