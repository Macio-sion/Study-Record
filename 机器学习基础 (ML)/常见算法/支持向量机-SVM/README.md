# 支持向量机 - SVM

支持向量机（Support Vector Machine, SVM）是一种监督学习算法，主要用于分类，也能做回归。它的核心思想非常几何化：在特征空间里找一条最优的分界线，把不同类别尽量分开，并且让这条线离两边的样本都尽可能远。

## 核心直觉：找“最宽的路”

想象二维平面上有两类点，红点和蓝点。你要画一条线把它们分开。

能分开的线有很多条，但 SVM 要的是最优的那一条——不仅能把两类分开，还要让这条线离最近的红点和最近的蓝点都尽量远。

这个“尽量远”的间隙，叫间隔（margin）。SVM 的目标就是最大化间隔。

## 支持向量：决定分界线的关键点

分界线的位置，其实只由少数几个点决定——就是那些离分界线最近的点。这些点叫支持向量（support vectors）。

其他离得远的点，怎么移动都不影响分界线。所以 SVM 的模型只依赖支持向量，这也是它名字的由来。

## 数学上的目标

SVM 要解的优化问题是：

```text
最大化  2 / ||w||        （即最大化间隔）
约束：  对于每个样本，分类正确且落在间隔之外
等价于：
```
```text
最小化  (1/2)||w||²
约束：  yᵢ(w·xᵢ + b) ≥ 1   （对所有样本）
w：分界线的法向量，决定方向
```
b：偏置，决定位置

||w|| 越小，间隔越大

这是一个凸二次规划问题，有全局最优解，不会陷入局部最优。
