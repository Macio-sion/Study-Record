# 通知公告模块 PRD

## 1. 模块概述

教务员/管理员发布系统通知公告，按角色控制可见范围，实现信息定向传达。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 公告发布 | P1 | 教务员/管理员发布；支持设定可见角色（全员/教师/学生） | |
| 公告列表 | P1 | 各角色查看可见公告列表 | |
| 公告已读标记 | P2 | 记录用户已读状态 | 二期迭代 |

## 3. 业务规则详述

### 3.1 发布权限
- 教务员和管理员可发布公告
- 发布时选择可见范围：全员、仅教师、仅学生

### 3.2 公告展示
- 按发布时间倒序排列
- 根据用户角色过滤可见公告
- 首页顶部展示最新公告（滚动/固定）

### 3.3 公告内容
- 标题 + 正文（富文本）
- 支持附件（可选）

## 4. 数据字典

### 公告表 (notices)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| title | VARCHAR(200) | 是 | 公告标题 |
| content | TEXT | 是 | 公告内容 |
| publisher_id | INT | 是 | 发布人ID，外键 |
| visible_to | VARCHAR(20) | 是 | 可见范围：all/teacher/student |
| is_published | TINYINT(1) | 是 | 是否已发布 |
| published_at | DATETIME | 否 | 发布时间 |
| created_at | DATETIME | 是 | 创建时间 |
