# 成绩管理模块 PRD

## 1. 模块概述

教师录入/修改学生成绩，学生查看本人成绩。成绩修改需记录操作日志，确保可追溯。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 成绩录入 | P0 | 教师按课程录入学生成绩（百分制0-100）；支持批量录入 | |
| 成绩修改 | P0 | 修改需记录操作日志（修改人/时间/原值/新值） | |
| 成绩查询（教师） | P0 | 教师查看所授课程成绩列表 | |
| 成绩查询（学生） | P0 | 学生查看本人各课程成绩 | |
| 成绩统计 | P1 | 按课程统计平均分/最高分/最低分/及格率 | |
| 成绩导出 | P2 | 导出成绩单为Excel | |

## 3. 业务规则详述

### 3.1 成绩录入
- 成绩范围：0-100（百分制）
- 录入场景：教师选择课程 → 加载选课学生名单 → 逐行或批量录入分数
- 必填校验：每个学生必须录入成绩才能提交

### 3.2 成绩修改日志
- 每次修改记录：修改人ID、修改时间、原值、新值、课程ID、学生ID
- 日志表不可删除，仅可查询

### 3.3 权限
- 教师：只能录入/修改自己授课课程的成绩
- 学生：只能查看自己的成绩
- 教务员/管理员：可查看全部成绩，但不可修改

### 3.4 成绩状态
- 草稿（draft）：教师录入中，未提交，学生不可见
- 已发布（published）：教师确认提交，学生可见
- 已锁定（locked）：教务员锁定，不可再修改

## 4. 数据字典

### 成绩表 (scores)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| student_id | INT | 是 | 学生ID，外键 |
| course_id | INT | 是 | 课程ID，外键 |
| semester_id | INT | 是 | 学期ID，外键 |
| score | DECIMAL(5,1) | 是 | 成绩（0-100） |
| status | VARCHAR(20) | 是 | 状态：draft/published/locked |
| teacher_id | INT | 是 | 录入教师ID，外键 |
| created_at | DATETIME | 是 | 创建时间 |
| updated_at | DATETIME | 是 | 更新时间 |

**唯一索引**：`uk_student_course_semester (student_id, course_id, semester_id)`

### 成绩修改日志表 (score_logs)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| score_id | INT | 是 | 成绩记录ID |
| old_score | DECIMAL(5,1) | 是 | 原值 |
| new_score | DECIMAL(5,1) | 是 | 新值 |
