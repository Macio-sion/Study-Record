# 学生管理模块 PRD

## 1. 模块概述

管理学生基本信息，支持批量导入，与系统用户关联。学生数据是选课、成绩、考勤等模块的前置依赖。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 学生信息增删改查 | P0 | 学号唯一；关联专业/班级；关联系统用户 | |
| 学生批量导入 | P0 | Excel模板导入；逐行校验；返回导入报告 | 异步处理 |
| 学生信息导出 | P2 | 导出当前筛选结果为Excel | |
| 班级管理 | P0 | 班级编号唯一；关联专业；关联辅导员（教师） | |

## 3. 业务规则详述

### 3.1 新增学生
1. 在系统用户表创建用户（角色=student，用户名=学号，初始密码=学号）
2. 在学生表创建学生记录
3. 以上两步在同一事务中完成

### 3.2 删除学生
- 删除前校验：是否有关联选课/成绩/考勤记录，有则拒绝删除
- 删除学生时同步禁用系统用户

### 3.3 批量导入流程
同教师批量导入，Excel模板字段：
| 学号 | 姓名 | 性别 | 专业编码 | 班级编号 | 入学年份 | 手机号 |

### 3.4 班级管理
- 班级编号格式：专业编码 + 2位序号，如 `01011`
- 班级需指定辅导员（关联教师表）
- 删除班级前校验是否有学生关联

## 4. 数据字典

### 班级表 (classes)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| class_no | VARCHAR(20) | 是 | 班级编号，唯一 |
| name | VARCHAR(100) | 是 | 班级名称 |
| major_id | INT | 是 | 所属专业ID，外键 |
| advisor_id | INT | 否 | 辅导员ID（教师），外键 |
| grade | INT | 是 | 入学年份 |
| created_at | DATETIME | 是 | 创建时间 |

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |

| user_id | INT | 是 | 关联系统用户ID，外键 |

| created_at | DATETIME | 是 | 创建时间 |
| updated_at | DATETIME | 是 | 更新时间 |
