# 系统管理模块 PRD

## 1. 模块概述

系统管理是教务管理系统的基石模块，负责用户认证、角色权限控制、系统配置。所有其他模块均依赖此模块的认证与鉴权能力。

## 2. 角色定义

| 角色 | 编码 | 权限范围说明 |
| :--- | :--- | :--- |
| 超级管理员 | `admin` | 全部功能，含系统配置、用户管理、角色权限管理 |
| 教务员 | `academic_staff` | 学生管理、教师管理、课程管理、排课管理、选课管理、成绩管理、教室管理、点名系统、考勤统计、作业管理、请假审批、学业预警、社团管理、通知公告 |
| 教师 | `teacher` | 查看课表、点名、录入/查看成绩、发布/批阅作业、请假审批、查看课表、考勤统计（本班） |
| 学生 | `student` | 查看课表、选课/退课、查看成绩、提交作业、请假申请、考勤统计（本人） |

## 4. 业务规则详述

### 4.1 认证流程
1. 用户提交用户名+密码
2. 后端查询用户，bcrypt验证密码
3. 验证通过后生成JWT Token，包含：user_id、username、role_code
4. Token有效期2小时，过期需重新登录
5. 前端所有请求在Header中携带 `Authorization: Bearer <token>`

### 4.2 权限控制
- 前端：根据用户角色动态渲染菜单（从后端获取角色菜单配置）
- 后端：每个接口装饰器校验 `@require_role("admin")` 或 `@require_roles(["admin", "academic_staff"])`
- 越权访问返回 403
