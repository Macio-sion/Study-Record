# 考勤统计模块 PRD

## 1. 模块概述

基于点名系统的出勤数据，按课程和学生维度统计出勤率，提供可视化图表展示，为学业预警提供数据支撑。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 课程出勤率统计 | P0 | 按课程统计每次课出勤率 | 可视化图表 |
| 学生出勤率统计 | P0 | 按学生统计个人出勤率 | 可视化图表 |
| 缺勤预警 | P1 | 出勤率低于阈值触发预警 | 关联学业预警 |

## 3. 业务规则详述

### 3.1 出勤率计算
- 课程出勤率 = 该课程到课学生数 / 应到学生数 × 100%
- 学生出勤率 = 该学生到课次数 / 应到课次数 × 100%

### 3.2 可视化
- 课程维度：柱状图展示各课程出勤率对比
- 学生维度：饼图展示个人出勤状态分布
- 趋势图：按周统计出勤率变化趋势

### 3.3 权限
- 教师：查看自己授课课程出勤率 + 本班学生出勤率
- 学生：查看个人出勤率
- 教务员/管理员：查看全部统计

### 3.4 缺勤预警
- 出勤率低于阈值（默认70%）的学生自动进入预警名单
- 在学业预警模块统一处理

## 4. 数据字典

本模块基于出勤记录表（attendances）做聚合查询，不单独建表。
