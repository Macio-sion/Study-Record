# 排课管理模块 PRD

## 1. 模块概述

根据课程、教师、教室、班级等约束条件，自动或手动安排课程的上课时间与地点。排课是教务系统的核心调度模块。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 自动排课 | P0 | 按学期+周次+星期+节次排课；自动检测冲突 | 异步任务 |
| 手动调整排课 | P0 | 表单修改排课安排；实时冲突检测 | |
| 排课冲突检测 | P0 | 教师/教室/班级三维冲突检测 | |
| 排课结果导出 | P2 | 导出Excel | |

## 3. 业务规则详述

### 3.1 排课时间模型
- 学期：如 `2025-2026-1`
- 周次：1-16周（教学周）
- 星期：周一至周日（1-7）
- 节次：1-2节、3-4节、5-6节、7-8节、9-10节（每2节为一个时段）

### 3.2 冲突检测规则（三维约束）
1. **教师冲突**：同一教师在同一时段（周次+星期+节次）不可安排多门课程
2. **教室冲突**：同一教室在同一时段不可安排多门课程
3. **班级冲突**：同一班级在同一时段不可安排多门课程

### 3.3 自动排课算法
- 输入：待排课程列表、可用教室列表、教师可用时间
- 约束：冲突检测三维约束
- 输出：排课结果列表
- 处理方式：异步任务，前端轮询获取进度

### 3.4 手动调整
- 教务员可修改已排课程的时间/教室
- 修改时实时校验冲突，有冲突则提示并阻止保存
