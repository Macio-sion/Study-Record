# 社团管理模块 PRD

## 1. 模块概述

管理学校社团基本信息及成员，为课外活动管理提供基础能力。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 社团增删改查 | P1 | 社团名称唯一；需指定指导老师 | |
| 社团成员管理 | P1 | 添加/移除成员；查看成员列表 | |
| 社团活动发布 | P2 | 社团发布活动信息 | 二期迭代 |

## 3. 业务规则详述

### 3.1 社团创建
- 社团名称唯一
- 需指定指导老师（关联教师表）
- 创建后默认创建者为社团负责人

### 3.2 成员管理
- 添加成员：从学生列表中选择
- 移除成员：从社团成员列表中移除
- 成员角色：负责人（1人）、干事、普通成员

### 3.3 删除校验
- 删除社团时需先清空成员

## 4. 数据字典

### 社团表 (clubs)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| name | VARCHAR(100) | 是 | 社团名称，唯一 |
| description | VARCHAR(500) | 否 | 社团描述 |
| advisor_id | INT | 是 | 指导老师ID，外键 |
| created_at | DATETIME | 是 | 创建时间 |

### 社团成员表 (club_members)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| club_id | INT | 是 | 社团ID，外键 |
| student_id | INT | 是 | 学生ID，外键 |
| role | VARCHAR(20) | 是 | 角色：leader/manager/member |
| joined_at | DATETIME | 是 | 加入时间 |

**唯一索引**：`uk_club_student (club_id, student_id)`
