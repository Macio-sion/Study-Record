# 课表系统模块 PRD

## 1. 模块概述

为不同角色提供课表查看功能。教师看授课安排，学生看上课安排，教务员看全局课表。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 教师课表 | P0 | 按本周+星期+节次展示授课安排 | 周视图 |
| 学生课表 | P0 | 按本周+星期+节次展示上课安排 | 周视图 |
| 教务员全局课表 | P0 | 支持按班级/教师/教室多维度查询 | |

## 3. 业务规则详述

### 3.1 教师课表视图
- 展示当前教学周每天的授课安排
- 每节课显示：课程名称、班级、教室、节次
- 数据来源：排课结果表，按 `teacher_id + 当前周次` 筛选

### 3.2 学生课表视图
- 展示当前教学周每天的上课安排
- 每节课显示：课程名称、教师、教室、节次
- 数据来源：选课记录表 + 排课结果表，按 `student_id + 当前周次` 筛选

### 3.3 教务员全局课表
- 支持多维度筛选：按班级、按教师、按教室
- 展示完整排课数据

### 3.4 当前周次计算
- 根据学期表 `start_date` 和当前日期计算所在教学周
- 公式：`当前周次 = CEIL((当前日期 - 学期开始日期) / 7)`

### 3.5 周视图UI
- 横向：周一至周日（7列）
- 纵向：节次时段（5行）
- 每个格子显示课程信息卡片
