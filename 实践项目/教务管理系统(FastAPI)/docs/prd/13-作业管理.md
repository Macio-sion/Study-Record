# 作业管理系统模块 PRD

## 1. 模块概述

教师发布作业（含附件），学生提交作业，教师批阅打分。覆盖作业全生命周期管理。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 作业发布 | P0 | 教师发布作业（标题+内容+截止时间+附件） | |
| 附件上传 | P0 | 支持PDF/Word/图片上传 | 大小限制10MB |
| 作业列表（学生） | P0 | 学生查看所修课程作业列表 | |
| 作业提交 | P0 | 学生提交作业（文本+附件） | 截止时间后不可提交 |
| 作业批阅 | P0 | 教师查看提交列表，打分/评语 | |
| 作业成绩统计 | P1 | 按课程统计作业提交率/平均分 | |

## 3. 业务规则详述

### 3.1 作业发布
- 教师选择课程 → 填写标题、内容描述 → 设置截止时间 → 上传附件（可选）
- 附件支持格式：PDF、Word(.doc/.docx)、图片(.jpg/.png)
- 单文件大小限制：10MB

### 3.2 作业提交
- 学生查看作业列表 → 选择作业 → 填写答案文本 → 上传附件（可选）→ 提交
- 截止时间后：提交按钮置灰，不可提交
- 截止时间前：可重新提交，覆盖之前提交

### 3.3 作业批阅
- 教师选择课程+作业 → 查看提交学生列表 → 逐人批阅
- 打分：百分制（0-100）
- 评语：文本，可选
- 已批阅作业：学生端可见分数和评语

### 3.4 权限
- 教师：只能管理自己授课课程的作业
- 学生：只能查看/提交自己所选课程的作业
- 教务员/管理员：可查看全部

## 4. 数据字典

### 作业表 (assignments)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| course_id | INT | 是 | 课程ID，外键 |
| teacher_id | INT | 是 | 发布教师ID，外键 |
| title | VARCHAR(200) | 是 | 作业标题 |
| content | TEXT | 是 | 作业内容描述 |
| file_path | VARCHAR(500) | 否 | 附件路径 |
| deadline | DATETIME | 是 | 截止时间 |
| created_at | DATETIME | 是 | 创建时间 |

### 作业提交表 (assignment_submissions)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| assignment_id | INT | 是 | 作业ID，外键 |
| student_id | INT | 是 | 学生ID，外键 |
| content | TEXT | 否 | 提交内容 |
| file_path | VARCHAR(500) | 否 | 提交附件路径 |
| score | DECIMAL(5,1) | 否 | 教师评分 |
| comment | VARCHAR(500) | 否 | 教师评语 |
| submitted_at | DATETIME | 是 | 提交时间 |
| reviewed_at | DATETIME | 否 | 批阅时间 |

**唯一索引**：`uk_assignment_student (assignment_id, student_id)`
