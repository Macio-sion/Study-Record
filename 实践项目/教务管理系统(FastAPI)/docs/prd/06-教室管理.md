# 教室管理模块 PRD

## 1. 模块概述

管理学校教室资源信息，为排课管理提供教室数据依赖。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 教室增删改查 | P0 | 教室编号唯一；需标注容量/类型 | |
| 教室状态查询 | P0 | 按时间段查询教室占用情况 | |

## 3. 业务规则详述

### 3.1 教室类型
- 普通教室：标准课桌椅，无多媒体设备
- 多媒体教室：配备投影仪/电脑
- 实验室：计算机房/物理实验室/化学实验室等

### 3.2 删除校验
- 删除教室前检查是否有关联排课记录，有则拒绝

## 4. 数据字典

### 教室表 (classrooms)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| room_no | VARCHAR(20) | 是 | 教室编号，唯一 |
| name | VARCHAR(100) | 是 | 教室名称 |
| building | VARCHAR(50) | 是 | 所在教学楼 |
| capacity | INT | 是 | 容量（座位数） |
| type | VARCHAR(20) | 是 | 教室类型：normal/multimedia/lab |
| status | VARCHAR(10) | 是 | 状态：available/maintenance |
| created_at | DATETIME | 是 | 创建时间 |
