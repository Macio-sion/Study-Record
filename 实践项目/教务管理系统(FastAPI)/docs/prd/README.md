## 1. 项目概述

### 1.1 项目目标
构建一套功能完整的企业级教务管理系统，覆盖学生管理、课程管理、排课调度、成绩管理、教师管理、考勤统计、权限控制等核心模块，面向百人规模用户，提供高效、稳定的教务管理服务。

### 1.2 MVP范围
- P0（必做）：38个功能点，覆盖系统管理、学院专业、教师管理、学生管理、课程管理、教室管理、排课管理、选课管理、课表系统、点名系统、考勤统计、成绩管理、作业管理
- P1（二期）：12个功能点，覆盖请假审批、学业预警、社团管理、通知公告
- P2（三期）：8个功能点，覆盖操作日志、报表导出、成绩分制扩展

### 1.3 非功能性需求
| 指标 | 目标值 |
| :--- | :--- |
| 普通查询响应时间 | ≤ 500ms（P95） |
| 复杂查询响应时间 | ≤ 3s，异步返回 |
| 峰值并发用户 | 100人同时在线 |
| 认证机制 | JWT Token，2h过期 |
| 密码存储 | bcrypt加密 |
| 界面风格 | ElementPlus，简洁专业 |

## 2. 角色定义

| 角色 | 编码 | 权限概述 |
| :--- | :--- | :--- |
| 超级管理员 | `admin` | 全部功能，含系统配置、用户管理 |
| 教务员 | `academic_staff` | 教务核心业务管理，含预警、社团、公告 |
| 教师 | `teacher` | 授课相关：课表、点名、成绩、作业、请假审批 |
| 学生 | `student` | 学习相关：课表、选课、成绩、作业提交、请假申请 |
