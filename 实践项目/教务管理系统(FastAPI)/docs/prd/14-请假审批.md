# 请假审批模块 PRD

## 1. 模块概述

学生提交请假申请，经教师一级审批、教务员二级审批（终审），支持多角色审批流程。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 请假申请 | P1 | 学生提交（课程+日期+请假类型+原因） | 类型：事假/病假/公假 |
| 教师审批 | P1 | 教师审批（通过/驳回+意见） | 一级审批 |
| 教务员审批 | P1 | 教务员终审（通过/驳回+意见） | 二级审批 |
| 审批记录查询 | P1 | 按角色查看审批历史 | |

## 3. 业务规则详述

### 3.1 请假类型
- 事假（personal）：个人事务
- 病假（sick）：因病请假
- 公假（official）：学校安排的公务活动

### 3.2 审批流程
```
学生提交申请（选择课程+日期+类型+原因）
    → 教师审批（一级）
        → 驳回 → 流程结束，学生收到驳回通知
        → 通过 → 进入教务员审批（二级）
            → 驳回 → 流程结束，学生收到驳回通知
            → 通过 → 流程结束，请假生效
```

### 3.3 审批状态
- 待教师审批（pending_teacher）
- 待教务员审批（pending_staff）
- 已通过（approved）
- 已驳回（rejected）

### 3.4 审批权限
- 教师：只能审批自己授课课程相关的请假
- 教务员：审批所有经教师通过的请假
- 学生：可查看自己请假申请的审批进度

## 4. 数据字典

### 请假申请表 (leave_requests)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| student_id | INT | 是 | 学生ID，外键 |
| course_id | INT | 是 | 课程ID，外键 |
| leave_type | VARCHAR(20) | 是 | 请假类型：personal/sick/official |
| leave_date | DATE | 是 | 请假日期 |
| reason | VARCHAR(500) | 是 | 请假原因 |
| status | VARCHAR(20) | 是 | 审批状态 |
| teacher_id | INT | 否 | 审批教师ID |
| teacher_opinion | VARCHAR(200) | 否 | 教师审批意见 |
| teacher_at | DATETIME | 否 | 教师审批时间 |
| staff_id | INT | 否 | 审批教务员ID |
| staff_opinion | VARCHAR(200) | 否 | 教务员审批意见 |
| staff_at | DATETIME | 否 | 教务员审批时间 |
| created_at | DATETIME | 是 | 申请时间 |
