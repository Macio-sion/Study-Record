# 学业预警模块 PRD

## 1. 模块概述

对缺勤率过高或成绩不及格的学生自动触发预警，教务员跟进处理，保障学生学业质量。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 预警规则配置 | P1 | 教务员配置：缺勤率阈值、不及格门数阈值 | |
| 预警名单生成 | P1 | 系统自动扫描符合条件的预警学生 | |
| 预警通知发送 | P1 | 向学生/辅导员推送预警通知 | |
| 预警处理记录 | P1 | 教务员记录处理结果 | |

## 3. 业务规则详述

### 3.1 预警触发条件（可配置）
- 缺勤率 ≥ 阈值（默认30%，即出勤率 < 70%）
- 成绩不及格门数 ≥ 阈值（默认2门）
- 以上条件满足任一即触发预警

### 3.2 预警等级
- 黄色预警：满足1项条件
- 橙色预警：满足2项条件
- 红色预警：满足3项及以上条件

### 3.3 预警流程
1. 系统定时扫描（或手动触发）
2. 生成预警学生名单
3. 向学生本人和辅导员发送通知
4. 教务员查看预警名单，逐一处理
5. 记录处理结果（已谈话/已通知家长/已制定帮扶计划等）

## 4. 数据字典

### 预警记录表 (alert_records)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| student_id | INT | 是 | 学生ID，外键 |
| semester_id | INT | 是 | 学期ID，外键 |
| alert_level | VARCHAR(20) | 是 | 预警等级：yellow/orange/red |
| attendance_rate | DECIMAL(5,2) | 否 | 出勤率 |
| failed_count | INT | 否 | 不及格门数 |
| status | VARCHAR(20) | 是 | 处理状态：pending/processing/resolved |
| handler_id | INT | 否 | 处理人ID |
| handle_result | VARCHAR(500) | 否 | 处理结果 |
| handled_at | DATETIME | 否 | 处理时间 |
| created_at | DATETIME | 是 | 触发时间 |
