# 点名系统模块 PRD

## 1. 模块概述

教师在每次上课时对学生进行出勤状态标记，支持批量操作，提高课堂管理效率。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 出勤标记 | P0 | 教师按课程+日期标记学生状态：到课/迟到/早退/缺勤 | 默认全勤，一键标记 |
| 出勤记录查询 | P0 | 按课程/学生/日期查询出勤记录 | |
| 批量标记 | P0 | 一键全勤/一键缺勤，再单独调整 | |

## 3. 业务规则详述

### 3.1 出勤状态
- **到课**（present）：正常出勤
- **迟到**（late）：上课后到达
- **早退**（early_leave）：下课前离开
- **缺勤**（absent）：未到课

### 3.2 点名流程
1. 教师选择课程 + 日期
2. 系统自动加载该课程选课学生名单
3. 默认全部学生状态为"到课"
4. 教师可一键切换某学生状态，或批量设为"缺勤"后再单独调整
5. 提交保存

### 3.3 查询规则
- 教师：只能查看自己授课课程的出勤记录
- 学生：只能查看自己的出勤记录
- 教务员/管理员：可查看全部出勤记录

## 4. 数据字典

### 出勤记录表 (attendances)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| course_id | INT | 是 | 课程ID，外键 |
| student_id | INT | 是 | 学生ID，外键 |
| teacher_id | INT | 是 | 点名教师ID，外键 |
| date | DATE | 是 | 上课日期 |
| status | VARCHAR(20) | 是 | 出勤状态：present/late/early_leave/absent |
| remark | VARCHAR(200) | 否 | 备注 |
| created_at | DATETIME | 是 | 创建时间 |
| updated_at | DATETIME | 是 | 更新时间 |

**唯一索引**：`uk_course_student_date (course_id, student_id, date)` 同一学生同一课程同一天仅一条记录
