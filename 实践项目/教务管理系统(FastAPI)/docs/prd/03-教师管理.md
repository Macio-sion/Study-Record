# 教师管理模块 PRD

## 1. 模块概述

管理教师基本信息，支持批量导入，与系统用户关联。教师数据是课程管理、排课管理的前置依赖。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 教师信息增删改查 | P0 | 工号唯一；关联学院；关联系统用户 | |
| 教师批量导入 | P0 | Excel模板导入；逐行校验（工号唯一性、必填字段）；返回导入报告 | 异步处理 |
| 教师信息导出 | P2 | 导出当前筛选结果为Excel | |
| 教师授课查询 | P0 | 查询某教师本学期所授课程列表 | |

## 3. 业务规则详述

### 3.1 新增教师
1. 在系统用户表创建用户（角色=teacher，用户名=工号，初始密码=工号）
2. 在教师表创建教师记录
3. 以上两步在同一事务中完成

### 3.2 删除教师
- 删除前校验：是否有关联课程（本学期授课），有则拒绝
- 删除教师时同步禁用系统用户（is_active=0）

### 3.3 批量导入流程
1. 教务员下载Excel模板
2. 按模板填写教师信息
3. 上传Excel文件
4. 后端异步处理：逐行校验 → 创建用户+教师记录 → 返回导入报告
5. 导入报告：成功X条，失败Y条，失败原因明细

### 3.4 Excel模板字段
| 工号 | 姓名 | 性别 | 学院编码 | 职称 | 手机号 | 邮箱 |

## 4. 数据字典

| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| teacher_no | VARCHAR(20) | 是 | 工号，唯一 |
