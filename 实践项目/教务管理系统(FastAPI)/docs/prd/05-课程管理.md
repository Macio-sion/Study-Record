# 课程管理模块 PRD

## 1. 模块概述

管理课程基本信息，按学期组织。课程数据是排课、选课、成绩模块的前置依赖。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 课程增删改查 | P0 | 课程编码唯一；按学期隔离；需指定学分/容量/授课教师 | |
| 课程列表查询 | P0 | 支持按学期/学院/教师多条件筛选 | |
| 课程容量管理 | P0 | 已选人数实时显示；不可超容量选课 | |

## 3. 业务规则详述

### 3.1 学期概念
- 学期格式：`YYYY-YYYY-N`，如 `2025-2026-1`（2025-2026学年第一学期）
- 所有排课、选课、成绩数据均按学期隔离
- 需要学期管理基础表，预置当前学期

### 3.2 课程编码规则
- 格式：`学院编码 + 4位序号`，如 `010001`
- 同一学期内课程编码不可重复

### 3.3 容量管理
- 课程创建时设定最大容量（如60人）
- 已选人数 = 选课表中该课程关联学生数
- 已选人数 >= 最大容量时，选课接口拒绝新选课

## 4. 数据字典

### 学期表 (semesters)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| name | VARCHAR(20) | 是 | 学期名称，如 2025-2026-1 |
| start_date | DATE | 是 | 学期开始日期 |
| end_date | DATE | 是 | 学期结束日期 |
| is_current | TINYINT(1) | 是 | 是否当前学期 |

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |

| name | VARCHAR(200) | 是 | 课程名称 |
| semester_id | INT | 是 | 所属学期ID，外键 |

| teacher_id | INT | 是 | 授课教师ID，外键 |
| credit | DECIMAL(3,1) | 是 | 学分 |

| hours | INT | 是 | 总学时 |
| type | VARCHAR(20) | 是 | 课程类型：必修/选修 |
| description | VARCHAR(500) | 否 | 课程描述 |
| created_at | DATETIME | 是 | 创建时间 |
| updated_at | DATETIME | 是 | 更新时间 |
