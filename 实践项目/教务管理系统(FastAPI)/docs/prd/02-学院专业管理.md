# 学院与专业管理模块 PRD

## 1. 模块概述

管理学校组织结构数据，学院下辖多个专业，专业下辖多个班级。为学生管理、教师管理提供基础数据依赖。

## 2. 功能列表

| 功能点 | 优先级 | 业务规则简述 | 备注 |
| :--- | :---: | :--- | :--- |
| 学院增删改查 | P0 | 学院编码唯一；删除需校验下属无专业 | |
| 专业增删改查 | P0 | 专业编码唯一；归属学院；删除需校验无关联学生 | |
| 学院-专业级联查询 | P0 | 前端级联选择器（选择学院 → 自动加载下属专业） | |

## 3. 业务规则详述

### 3.1 删除校验
- 删除学院前：检查下属是否有专业，有则拒绝删除，提示"请先删除下属专业"
- 删除专业前：检查是否有学生关联，有则拒绝删除，提示"该专业下存在学生，无法删除"

### 3.2 编码规则
- 学院编码：2位数字，如 `01`（计算机学院）、`02`（数学学院）
- 专业编码：4位数字，前2位为学院编码，如 `0101`（计算机科学与技术）

## 4. 数据字典

### 学院表 (colleges)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| code | VARCHAR(10) | 是 | 学院编码，唯一 |
| name | VARCHAR(100) | 是 | 学院名称 |
| description | VARCHAR(500) | 否 | 学院描述 |
| created_at | DATETIME | 是 | 创建时间 |
| updated_at | DATETIME | 是 | 更新时间 |

### 专业表 (majors)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :---: | :--- |
| id | INT | 是 | 主键，自增 |
| code | VARCHAR(10) | 是 | 专业编码，唯一 |
| name | VARCHAR(100) | 是 | 专业名称 |
| college_id | INT | 是 | 所属学院ID，外键 |
| duration | INT | 是 | 学制（年），默认4 |
| degree | VARCHAR(20) | 是 | 学位类型（学士/硕士/博士） |
| created_at | DATETIME | 是 | 创建时间 |
| updated_at | DATETIME | 是 | 更新时间 |
