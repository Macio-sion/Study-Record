# 面试官出题知识库

> 本文件用于模拟「面试官出题」知识库，供模拟面试的题目生成做参考依据。
> 每个 `##` 二级标题可作为一个可检索的知识块。

## 技术面出题要点

技术面出题应基于候选人简历中的技能栈，围绕「原理 → 实践 → 边界」设计：

1. **针对技能出题**：从简历技能列表（如 Python、Java）中选核心技能，问其底层原理（如「Python 的 GIL 是什么」）。
2. **结合项目追问**：针对项目经历中用到的技术，追问选型理由与实现细节。
3. **分层出题**：初级问基础概念与工具使用；中级问方案设计与问题解决；高级问架构与选型。
4. **避免纯背诵题**：优先问「为什么」「怎么做」「踩过什么坑」这类能体现真实经验的题。

## 行为面出题要点

行为面基于 STAR 法则设计，考察候选人的软素质：

- **团队协作**：「介绍一次你和同事发生分歧，如何解决的经历。」
- **抗压能力**：「描述一次项目延期或上线失败，你是如何应对的。」
- **主动性与成长**：「你主动做过哪些超出职责范围的事？」
- **冲突处理**：「遇到需求频繁变更，你怎么处理？」
- 每题都应能引出具体「情境 → 任务 → 行动 → 结果」。

## 案例面出题要点

案例面针对简历中的具体项目/经历追问，考察真实性：

1. **深挖细节**：「这个项目的技术选型为什么这么定？」
2. **追问挑战**：「遇到的最大挑战是什么？如何解决？」
3. **量化结果**：「你负责的模块性能提升了多少？怎么衡量？」
4. **复盘反思**：「如果重来一次，你会怎么做？」
5. 优先挑选简历中描述最具体、最有含金量的经历来出题。

## 难度分级出题标准

按岗位级别调整题目深度：

- **初级（0-2年）**：基础概念、工具使用、简单场景题。
- **中级（3-5年）**：方案设计、问题解决、团队协作题。
- **高级（5-8年）**：架构设计、技术选型、团队管理题。
- **专家（8年+）**：技术战略、行业趋势、创新突破题。
