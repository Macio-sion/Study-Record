# 面试辅导知识库

> 本文件用于模拟「外部知识库」，供简历智能问答的面试辅导（agent 模拟候选人作答）做 RAG 增强。
> 每个 `##` 二级标题可作为一个可检索的知识块。

## STAR 法则答题框架

STAR 是行为面/案例面面试题的标准答题结构，四个要素缺一不可：

- **Situation（情境）**：一句话交代项目背景、业务场景、团队规模。
- **Task（任务）**：你在其中承担的具体职责与目标。
- **Action（行动）**：你采取了哪些具体方法、技术、动作。
- **Result（结果）**：用数据说话——性能提升、成本下降、业务增长等量化成果。

示例（后端开发经历）：
「在 XX 系统日均请求量增长到 10 万、接口频繁超时的背景下（S），我负责核心链路性能优化（T），采用缓存预热 + 索引优化 + 异步化改造三项措施（A），将 P99 响应时间从 800ms 降到 120ms，超时率下降 95%（R）。」

## 技术面试答题框架

技术面试回答遵循「结论先行 → 原理说明 → 结合实践 → 边界补充」：

1. **结论先行**：先用一句话给出明确答案。
2. **原理说明**：讲清底层原理，体现理解深度。
3. **结合实践**：举出自己在项目中怎么用、踩过什么坑、如何解决。
4. **边界补充**：主动说明适用场景、局限与权衡（trade-off）。

示例（问「依赖注入原理」）：先说明 DI 是控制反转的一种实现，再讲容器如何装配对象，最后结合自己在项目里的使用与遇到的问题。

## 行为面试答题要点

常见行为题及答题思路：

- 「介绍一次解决冲突的经历」→ 强调换位思考、沟通方式、最终共识与结果。
- 「你最大的缺点」→ 选一个真实但已改进的缺点，重点放在改进动作。
- 「为什么离开上一家公司」→ 正面表达职业规划，不抱怨前雇主。
- 「如何面对失败」→ 客观描述失败 → 归因 → 改进 → 后续成果。

## 案例/项目面试答题要点

介绍项目经历时：

1. 先一句话讲清项目是做什么、解决什么问题。
2. 强调你的角色与贡献，而不是团队整体。
3. 重点讲「挑战 + 你的解决方案 + 结果」。
4. 用数据量化：性能、效率、规模、收益。

高频追问：

- 「遇到的最大挑战是什么？」→ 选一个技术难度高且你能讲透的挑战。
- 「如果重来会怎么做？」→ 体现复盘与成长思维。

## 通用面试答题技巧

- 回答控制在 1~2 分钟，先总后分。
- 多用「我」承担主体，避免泛泛而谈「我们」。
- 每条结论尽量带一个数据或案例支撑。
- 遇到不会的问题，诚实承认 + 说明思考方向，不要硬编。
